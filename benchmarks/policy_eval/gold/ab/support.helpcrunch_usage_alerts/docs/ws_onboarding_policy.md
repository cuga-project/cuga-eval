# Usage Thresholds: Onboarding Policy

| Policy | Condition | Action | Notes |
|---|---|---|---|
| Recently onboarded | Earliest event of ANY type within 7 days | Exclude entirely: no tag, no email, no SF task | Protects new customers from premature alerts |
| Stale trial override | Customer tagged 'trial' but earliest event >90 days ago | Use standard thresholds instead of trial thresholds | Long-inactive trials should not get lenient trial thresholds |
